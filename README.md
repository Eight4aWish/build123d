# build123d workshop

Parametric CAD for 3D-printed hardware, written in [build123d](https://github.com/gumyr/build123d).
Two main themes: **Eurorack module faceplates** and **general 3D-printed parts**
(Gridfinity organisers, desk accessories, fixtures).

## Layout

| Folder | What's in it |
| --- | --- |
| [panels/](panels/) | Eurorack faceplate generators (one `.py` per module). See [panels/README.md](panels/README.md). |
| [hardware/](hardware/) | General printed parts: Gridfinity bins, headphone holder, switch caps, Z-rail bracket, vactrol potting. |
| [render/](render/) | Photoreal assembly-render pipeline (build123d → STL → Blender). See [render/README.md](render/README.md). |
| [reference/](reference/) | Vendor data, datasheets, label templates, photos (inputs, not generated). |
| [exports/](exports/) | Printable/CAD outputs (`.stl` / `.3mf` / `.step`), split into `panels/` and `hardware/`, plus PCB faceplates in [`exports/pcb/`](exports/pcb/). |
| [scripts/](scripts/) | Repo helpers. |

Every model is generated by running its script; the files in `exports/` are the
checked-in results for parts that are actually printed. Regenerate any of them
by running the matching script.

Faceplates can also be ordered as **PCBs** instead of printed —
[`panels/kicad_faceplate.py`](panels/kicad_faceplate.py) reads a panel script and
writes a KiCad board plus a JLCPCB-ready gerber zip. See
[exports/pcb/](exports/pcb/).

## Setup

This workspace uses the local virtual environment at `./.venv`.

```sh
# Prefer Homebrew Python 3.12 on macOS
/opt/homebrew/bin/python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -U pip
python -m pip install -r requirements.txt
```

## Generating a model

Each script is self-contained and exports via CLI flags. Most faceplate scripts
build a **base** solid plus a separate **labels** solid for 2-colour printing:

```sh
# view in the OCP CAD Viewer
./.venv/bin/python panels/duallpg.py

# export separate STLs for 2-colour printing
./.venv/bin/python panels/duallpg.py --export-mode base   --stl exports/panels/duallpg_base.stl
./.venv/bin/python panels/duallpg.py --export-mode labels --stl exports/panels/duallpg_labels.stl
```

Many faceplate scripts also support flush text (`--text-mode deboss|inlay`) and a
1:1 paper alignment template (`--template-svg out.svg`). Run a script with
`--help` for its full options.

### Desk headphone holder

```sh
./.venv/bin/python hardware/headphone_holder_build123d.py --stl exports/hardware/headphone_holder.stl
```

The profile is copied from [hardware/drawing.svg](hardware/drawing.svg) (kept next
to the script). For friction fits start with `--fit-clearance 0.3` (PLA) or
`0.4–0.6` (PETG) and iterate.

## VS Code viewer

Install the **OCP CAD Viewer** extension (`bernhard-42.ocp-cad-viewer`).

1. Command Palette → **Python: Select Interpreter** → choose `./.venv/bin/python` (Python 3.12).
2. Command Palette → **OCP CAD Viewer: Open Viewer**.
3. Run any script, e.g. `./.venv/bin/python panels/amyboard.py`.

If the script runs but the viewer stays empty, make sure the OCP backend terminal
is running. To override host/port, copy `.env.example` to `.env` and set
`OCP_VSCODE_HOST` / `OCP_VSCODE_PORT`.

## macOS "Not Opened" (Gatekeeper) dialogs

Native extensions in the venv (`*.so` / `*.dylib`) can get quarantined. Clear it:

```sh
xattr -dr com.apple.quarantine .venv/lib/python*/site-packages
# or:
./scripts/unquarantine_venv.sh
```
